# STUDENT-GRADE-MANAGEMENT-SYSTEM

Student Grade Management System is a web-based application developed to manage and maintain student academic information efficiently. The system allows administrators, teachers, and students to access and manage student records such as grades, personal details, and academic performance.
The application provides a user-friendly interface where teachers can update student marks and academic information, while students can securely log in to view their grades and details.

Technologies Used:
Python
Flask
HTML
CSS
SQL / Database

Key Features:
-Student and teacher login system
-View and manage student details
-Store and update student grades
-Display academic results for students
-User-friendly web interface
